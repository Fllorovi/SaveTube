# Инструкция по запуску SaveTube

## 1. Предварительные требования
Установите:
*   Node.js (v18+)
*   Python (v3.10+)
*   FFmpeg (добавьте в PATH)
*   Deno (для обхода защиты YouTube)
*   VPN-клиент с поддержкой SOCKS5 (например, v2rayN, Nekobox) на порту `7890`.

## 2. Установка зависимостей
```bash
npm install
python -m pip install -U yt-dlp bgutil-ytdlp-pot-provider
3. Настройка окружения
Создайте файл .env.local в корне проекта:

env
NEXT_PUBLIC_SUPABASE_URL=ваш_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_ключ
4. Запуск
Включите VPN (порт 7890).

В отдельном терминале запустите сервер токенов:


python -m bgutil_ytdlp_pot_provider
В основном терминале запустите проект:

npm run dev
