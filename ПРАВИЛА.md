# Правила проекта SaveTube

## 1. Границы MVP
**Входит:** Вставка ссылки → выбор битрейта (128/320) → конвертация → скачивание MP3. Простой UI без регистрации. Локальная история скачиваний (localStorage).
**Не входит (на потом):** Плейлисты, аккаунты, выбор видео-формата, обрезка аудио, мобильное приложение, облачные хранилища.

## 2. Технические ограничения
*   Длительность видео: не более 2 часов (7200 секунд).
*   Размер файла: не более 100 МБ.
*   Плейлисты отклоняются с ошибкой.

## 3. Безопасность (Три строки)
*   **Ключи только на сервере:** Секретные ключи (Supabase, VPN, PO Token) хранятся в `.env.local` и не передаются в браузер.
*   **Проверка «чья запись»:** Пользователь не может изменить или удалить чужую конвертацию (проверка по UUID задачи).
*   **Ошибки словами:** Каждая ошибка (сеть, лимит, неверная ссылка) отображается пользователю понятным текстом, а не техническим кодом.

## 4. Правила разработки
*   Сначала план, потом код.
*   Не больше двух файлов за шаг.
*   Без новых библиотек без спроса.

## 5. Развертывание
*   `tests.html` лежит в корне для быстрой проверки.
*   Ключи хранятся только в настройках хостинга (Vercel Environment Variables), а не в коде.
*   `ЗАПУСК.md` обновляется при каждом добавлении новой зависимости.
